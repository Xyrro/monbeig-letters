# 蒙贝格神父书信 · Lettres du P. Théodore Monbeig (1897–1912)

在线阅读：https://xyrro.github.io/monbeig-letters/

巴黎外方传教会（MEP）西藏传教区传教士泰奥多尔·蒙贝格（Théodore Monbeig）的 9 封亲笔信，写于 1897 年至 1912 年，从他在波城服兵役时写起，一直写到在滇西北茨菇、茨中一带传教的岁月。页面左栏为法文原文转录，右栏为中文译文，逐段对照；也可以只看中文或只看法文。

- 来源：IRFA（Institut de recherche France-Asie）档案，卷宗 4CTi-MAR-020，扫描件 20 张。
- 转录与译文根据扫描件辨认整理，标有“?”的人名、地名和字词请以原件为准。
- 整个网站只有一个静态页面 `index.html`，不需要构建。
